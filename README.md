# اندیکاتور مکدی برای متاتریدر 5# MACD Pro - Advanced MACD Indicator for MetaTrader 5## OverviewA professional-grade MACD (Moving Average Convergence Divergence) indicator for MetaTrader 5## Features* **MACD Line** (Blue): Difference between 12-period and 26-period exponential moving averages* **Signal Line** (Red): 9-period exponential moving average of the MACD line* **Histogram** (Green/Red): Visual representation of MACD-Signal divergence  * Green bars indicate positive histogram values (bullish momentum)  * Red bars indicate negative histogram values (bearish momentum)## Parameters|Parameter|Default|Description||-|-|-||FastEMA|12|Period for fast exponential moving average||SlowEMA|26|Period for slow exponential moving average||SignalEMA|9|Period for signal line EMA||PriceType|Close|Applied price (Close, Open, High, Low, etc.)|### Trading Signals* **Bullish Signal**: MACD crosses above the Signal line with positive histogram* **Bearish Signal**: MACD crosses below the Signal line with negative histogram* **Momentum Strength**: Histogram height indicates momentum intensity* **Divergence**: Price highs/lows not confirmed by MACD highs/lows suggest potential reversals### Best Practices1. **Combine with other indicators** - Use alongside support/resistance, trend lines, or volume analysis2. **Confirm on higher timeframes** - Validate signals on daily or weekly charts3. **Avoid ranging markets** - MACD performs best in trending conditions4. **Monitor divergences** - Watch for hidden divergences indicating trend continuation## Technical Specifications* **Calculation Method**: Exponential Moving Average (EMA)* **Display Window**: Separate subwindow (oscillator)* **Color Scheme**: Blue (MACD), Red (Signal), Green/Red (Histogram)* **Line Width**: 2px (MACD/Signal), 3px (Histogram)* **Precision**: Values match MetaTrader 5 built-in MACD(12,26,9) indicator exactly* **Smoothing**: Exponential smoothing with proper initialization for accurate signal line calculation## Compatibility* **Platform**: MetaTrader 5* **Language**: MQL5* **Timeframes**: All (M1, M5, M15, H1, H4, D1, W1, MN1)* **Asset Classes**: Forex, Stocks, Commodities, Cryptocurrencies## Notes* Indicator requires minimum 35 bars for full calculation (SlowEMA + SignalEMA)* First values appear after sufficient historical data is loaded* Real-time updates on each new candle close* Customizable parameters allow optimization for different trading strategies## Version**1.00** -
